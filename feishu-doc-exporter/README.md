# 飞书文档导出助手

批量勾选并导出飞书云文档里的**图片（原图）**和**表格**，打包成一个 ZIP。

## 安装（Chrome / Edge，一次性 1 分钟）

1. 解压本文件夹到任意固定位置（不要放在临时目录，扩展会记住这个路径）。
2. 打开 `chrome://extensions/`（Edge 是 `edge://extensions/`）。
3. 打开右上角 **开发者模式**。
4. 点 **加载已解压的扩展程序**，选择解压出来的这个文件夹（含 `manifest.json` 的那一层）。
5. 工具栏出现「飞书导出」图标即完成。

## 使用

1. 打开任意飞书云文档（`*.feishu.cn/docx/...`、`*.feishu.cn/wiki/...`，或正文嵌在
   `/base/` 页面里的文档）。
2. 正文右下角会出现 **导出** 悬浮按钮，点开。
3. 点 **扫描文档**。长文档需要自动滚动逐段收集，100 张图的文档大约 1–2 分钟，
   期间**不要自己滚动页面**（会干扰收集）。扫描时按钮变成「停止」。
4. 扫描完成后是图片网格 + 表格列表，点卡片勾选/取消，或用 **全选 / 清空**。
5. 点 **导出选中（N 图 / M 表）**，浏览器下载一个 ZIP。

## 导出内容

```
<文档名>_<日期_时间>.zip
├── images/
│   ├── img_001_<blockId>.png   ← 原图（不是页面上那张压缩预览图）
│   └── ...
├── tables/
│   ├── table_01.csv            ← UTF-8 BOM，Excel 直接打开不乱码
│   └── ...
└── index.md                    ← 清单：来源链接、时间、每张图的尺寸与所属章节
```

## 已知限制

- **只能导出正文里可见的图片和表格**。文档里的「嵌入电子表格 / 电子表格块」目前
  只识别不导出（面板里会列出来并标注）。
- 图片按页面渲染顺序编号；`所属：<章节>` 来自就近的标题块。
- 超大文档（200 张以上原图、单张几 MB）ZIP 会有几百 MB，建议分批勾选导出。
- 只读预览状态下也能用；需要登录的文档请先在浏览器里登录好。

## 原理（给要改代码的人）

- `src/scan.js`：飞书 docx 正文是**虚拟滚动**，DOM 只保留视口附近十几个块，滚动时
  懒加载并卸载。所以扫描是"自上而下逐步滚动 + 按 `data-block-id` 去重累加"，不能
  用跳转定位（跳转会丢块）。
- 图片块内部 `<img>` 是 `blob:` 的压缩预览；原图走
  `/space/api/box/stream/download/all/<image-token>/?mount_point=docx_image`，
  `image-token` 从 `[image-token]` 属性取。
- 表格是真 `<table>`，单元格常是虚拟渲染占位符，需要进入视口并稍等才渲染出文字；
  解析时处理 `rowspan/colspan`。
- `src/zip.js`：无依赖的 STORE 模式 ZIP 打包。
- `src/panel.js`：悬浮面板、勾选状态、并发下载原图（4 路）、打包下载。
